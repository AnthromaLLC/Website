# Case Tracker App iOS

Anthroma Case Tracker - A modern web application for tracking USCIS immigration cases.

## Features

- Real-time case status tracking
- Privacy-focused design
- Responsive mobile and desktop interface
- Direct integration with USCIS APIs

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is automatically deployed to GitHub Pages via GitHub Actions.
